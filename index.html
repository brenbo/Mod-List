Part 1: Game Mod Installation

  1. Make sure your local game launcher runs a standard version of Fabric Loader.
  2. Click the gray Download button next to each required item above to download the files.
  3. Press Windows Key + R on your keyboard, type %appdata%\.minecraft and hit Enter.
  4. Open the folder named exactly: mods (or iris-reserved if you're using shaders).
  5. Drag and drop all downloaded core mod .jar files directly inside this folder.

Part 2: Optional Graphics Shaders Installation

  1. If you want shaders, open the Iris & Sodium Engine download link above and run the installer application. (Do not enable fabric mod support!)
  2. Go back out to the main .minecraft directory folder and open or create a folder named exactly: shaderpacks.
  3. Drag the downloaded ComplementaryUnbound.zip archive directly inside this folder (do not unzip or extract it!).
  4. Launch Minecraft by selecting the Iris and Sodium in the launcher, go to Options > Video Settings > Shader Packs, highlight the pack, and click to activate it!
