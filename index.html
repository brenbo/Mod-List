Installation Instructions
[Part 1: Game Mod Installation]
  1. Make sure your local game launcher runs a standard version of Fabric Loader.
  2. Download your mod files from the Modrinth page button above.
  3. Press Windows Key + R on your keyboard, type %appdata%\.minecraft and hit Enter.
  4. Open the folder named exactly: mods (if it is missing, right-click and create a new folder named mods here).
  5. Drag and drop your downloaded core mod .jar files directly inside this folder.
[Part 2: Optional Graphics Shaders Installation]
  1. If you want shaders, ensure you grab the Sodium and Iris mod files from Modrinth and place them into the same mods folder alongside your other mods.
  2. Go back out to the main .minecraft directory folder and open or create a folder named exactly: shaderpacks.
  3. Drag the downloaded ComplementaryUnbound.zip archive directly inside this folder (do not unzip or extract it!).
  4. Launch Minecraft, go to Options > Video Settings > Shader Packs, highlight the pack, and click to activate it!
